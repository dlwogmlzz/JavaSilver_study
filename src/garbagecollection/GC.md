[ガベージコレクタとは (가비지 컬렉터란)]
- 프로그램이 더 이상 이용하지 않게 된 영역을 검출하고 해제하는 것
- Java 실행 환경(JVM)에서 프로그램 실행 제어와 메모리 관리를 담당하고 있기 때문에, 메모리 해제용 코드를 기재할 필요가 없다

[객체를 가비지 컬렉터의 대상으로 삼으려면]
⇒ 변수로의 참조를 없앤다
① nullを代入する (null을 대입한다)
② 参照変数を他のオブジェクトに割り当てる (참조 변수를 다른 오브젝트에 할당한다)



class Sample {
String name;
    Sample(String name) {
        this.name = name;
    }
}

public class Main {
    public static void main(String[] args) {
        // 1. 첫 번째 객체 생성 및 참조 변수(obj)에 할당
        Sample obj = new Sample("첫 번째 객체");
        // 메모리 상태: [obj] ---> ["첫 번째 객체"] (참조 횟수: 1)
        // 2. 참조 변수에 새로운 객체를 할당 (재할당)
        obj = new Sample("두 번째 객체");
        // 메모리 상태: 
        // [obj] ---> ["두 번째 객체"] (새로운 객체 연결)
        // ["첫 번째 객체"]           (어떤 변수에서도 가리키지 않음 -> 가비지 컬렉터 대상이 됨!)
        // 설명:
        // 기존에 "첫 번째 객체"를 가리키고 있던 참조 변수 obj에 
        // 새로운 객체를 대입("두 번째 객체")함에 따라, 
        // 첫 번째 객체로 향하던 참조가 사라져 메모리 해제 대상이 됩니다.
    }
}

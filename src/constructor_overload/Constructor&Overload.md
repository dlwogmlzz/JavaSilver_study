
[생성자(Constructor)란?]

===================================================
⇒ 인스턴스화되었을 때 맨 처음 호출되는 메서드
  인스턴스화되었을 때 동시에 실행하고 싶은
  처리를 기재한다
===================================================
[생성자 정의 구문]
修飾子 コンストラクタ名(引数リスト) {

}

[생성자 호출 구문]
new コンストラクタ名()
new コンストラクタ名(引数リスト)
===================================================
[규칙 (ルール)]
* 생성자 이름이 클래스 이름과 같을 것
* 반환값을 가지지 않으며, 반환값 타입의 선언을 하지 않을 것
* 필요에 따라 인수의 수령이 가능할 것
===================================================


■디폴트 생성자
⇒ 생성자를 명시하지 않았을 경우, `생성자에 따라 자동적으로 추가되는 생성자.`

디폴트 생성자의 특징
①인수를 가지지 않는다.
②실장은 비어있음, 코드 작성X


[오버로드란 (オーバーロードとは)]
- 1개의 클래스 안에, 같은 이름의 메서드나 생성자를 복수 정의하는 것
  (1つのクラス内に、同じ名前のメソッドやコンストラクタを複数定義すること)
- `각각의 메서드를 구별하기 위해, 인수의 나열, 수, 데이터 타입이 다른 것이 조건`
  (それぞれのメソッドを区別するために、引数の並び、数、データ型が異なることが条件)
- `오버로드된 메서드는 다른 접근제어자를 지정할 수 있다`
  (オーバーロードされたメソッドは異なる修飾子を指定できる)

예


class MathUtils {
    // 인수가 정수 2개인 메서드
    int add(int a, int b) {
        return a + b;
    }
    // 조건: 인수의 `'개수'가 다른` 경우 (정수 3개)
    int add(int a, int b, int c) {
        return a + b + c;
    }
    // 조건: 인수의 `'데이터 타입'이 다른` 경우 (double 형)
    double add(double a, double b) {
        return a + b;
    }
    // 조건: 인수의 `'순서'가 다른` 경우 (int와 double)
    double add(int a, double b) {
        return a + b;
    }
}

public class Main {
    public static void main(String[] args) {
        MathUtils math = new MathUtils();
            System.out.println(math.add(10, 20));          // 30
            System.out.println(math.add(10, 20, 30));      // 60
            System.out.println(math.add(5.5, 2.1));        // 7.6
            System.out.println(math.add(10, 5.5));         // 15.5
    }
}


💡Point💡
인수의 나열, 수, 데이터 타입이 `똑같다면` 오버로드로 간주되지 않고 `컴파일에러`가 된다.



[コンストラクタのオーバーロード (생성자의 오버로드)]
⇒ コンストラクタに渡す引数の数や並び、データ型によって柔軟にインスタンス化できるようになる
(생성자에 전달하는 인수의 수나 나열, 데이터 타입에 따라 유연하게 인스턴스화할 수 있게 된다)

[例 (예)]
Public class Student {
    Student(){}
    Student(int id){}
    Student(int id, String name){}
}


[可変長引数とは (가변장 인수란)]
- 인수의 개수를 가변적으로 다룰 수 있다.
- 가변장 인수의 값은 배열로서 메서드에 전달된다.

[例 (예)]
Public class Student {
    Public static void main (String... args){
    }
}

[ルール (규칙)]
- 데이터형 뒤에 「`...`」을 기술한다.
- 가변장 인수와 데이터형이 다른 인수를 병용할 수 있다.
- `가변장 인수는 1개밖에 사용할 수 없다.`
- 인수 리스트를 명확히 정의한 메서드와 가변장 인수를 사용한 메서드가 있는 경우, 
  `인수 리스트를 명확히 정의한 메서드가 우선하여 호출된다.`



[可変長引数のオーバーロード (가변장 인수의 오버로드)]

[例 (예)]
Public class Main {
    Public void test(int a) {}
    Public void test(long a) {}
    Public void test(Integer a) {}
    `Public void test(int... a) {}`
    `Public void test(int[] a) {} // コンパイルエラー 可変長引数とみなされる (컴파일 에러: 가변장 인수로 간주됨)`
}

[Point]
オーバーロードされたメソッドを呼び出す優先順位 (오버로드된 메서드를 호출하는 우선순위)
`完全一致 > 暗黙型変換 > Boxing > 可変長引数`
(완전 일치 > 암묵형 변환 > Boxing > 가변장 인수)

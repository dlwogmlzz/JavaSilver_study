# 클래스와 오브젝트

・object - 데이터나 처리의 집합체
・class - 오브젝트를 작성하기 위한 설계도
・instance - 설계도인 클래스를 바탕으로 작성한 오브젝트 실체
・변수 - 오브젝트가 가지는 성질이나 속성
・메소드 - 오브젝트가 가지고 있는 처리

◆ 클래스의 정의

■수식자
⇒ 클래스의 공간범위나, 클래스의 특성을 지정할 수 있다.
  접근제어자라고도 불려짐.

■클래스명
⇒ class 키워드의 뒤에 설정하는 클래스 이름

【구문】
`수식자 class 클래스명`{}

■접근제어자(수식자)
public - 모든 클래스에서 접근 가능
protected - `1. 같은 패키지에 속하고 있는지`, `2. 상속하고 있는 서브 클래스에서만` 접근이 가능.
default(なし) - `같은 패키지에 속하고 있는 클래스에서만` 접근이 가능
private - `클래스내에만` 접근이 가능.


■변수의 선언

변수
⇒ `클래스가 가져야만 하는 속성`을 표현하기 위해 사용.
  클래스안에 선언된 변수를, `멤버 변수`라고 부른다.
  멤버변수에는, static변수와 instance변수가 있다.

instance변수
⇒ `object마다 존재하는 변수`
  클래스를 인스턴스화(객체 생성) 하지않으면 접근 불가능하다.

static변수
⇒ class에 대해서 존재하는 변수
  class를 인스턴스화(객체 생성) 하지않아도 접근 가능. 

변수 선언 구문
⇒ 오브젝트마다, 변수에 넣은 값이 바뀌기 때문에, `속성명(변수명)만 정의한다.`

【instance 변수 선언의 구문】
접근제어자 데이터형 instance변수명;

【static 변수 선언의 구문】
접근제어자 `static` 데이터형 static변수명;



■메서드의 정의

메서드
⇒ 그 클래스가 가져야만 하는 조작, 행동을 표현하기 위해 사용.
  메서드를 이용하는 것으로, `오브젝트와의 주고받음`이 가능하기 된다.

반환값
⇒ 메서드의 호출결과로서 반환하는 값.

【method 정의 구문】
접근제어자 `반환형` 메서드명(인수리스트) {}

【method를 반환하는 구문】
`return` 반환값;


■인스턴스화(객체 생성)

⇒ 클래스를 바탕으로, 오브젝트를 생성하는 것.
  `※오브젝트는 참조형의 데이터에 분류된다.`

【구문】
데이터형 변수명 = new 클래스명();

■정의한 멤버의 호출
⇒　어느 오브젝트에 대해서, 어느 멤버를 호출하고 싶은지를 나타냄

【구문】
변수명.메서드명();




■변수 다루는 법

변수 스코프
⇒ 변수를 사용할 수 있는 범위.

`local변수` 다루는데 주의
⇒ local변수는, 정의되어 있는 `블록 내에서만 사용할 수 있다.`


💡Point💡
로컬변수 = if문이나 for문 안에서 선언해서 다루는 변수나 인수리스트의 변수등.

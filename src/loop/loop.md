# 반복문이란?

⇒ 지정한 회수나 조건식이 참이 되어 있는 동안 블록 내의 처리를 반복 행하는 문
Java 언어에서 준비 되어있는 조건 분기문
     ╰while문
     ╰for문

■ while문
⇒반복처리안에서 조건을 만족하는 경우는
 횟수를 정하지 않고 반복(루프)을 행한다.

while(조건식) {
    처리문;        // 조건식의 결과가 true일때, 실행된다.
}

예
int num = 0;
while (num < 5) {   // num의 값이 5미만의 경우, 반복처리를 한다.
    System.out.println(num + " ");
    num++;  // num의 값에 1가산
}



■ do-while문
⇒기본적인 동작은 while문과 같지만, while문과는 다르고, 반복처리를 먼저 행한다.

do {
    처리문;        // 반복처리
} while(조건식);

예
int num = 0;
do {    // 반복처리의 실행
    System.out.println(num + " ");
    num++;          // num의 값에 1가산
} while(num < 5);   // 반복처리를 계속할지 판정함.


■ for文
⇒ 条件式だけでなく、繰り返し回数を指定できる繰り返し文

[기본 문법 구조]
for (繰返しカウントの定義; 繰返し回数の定義; 繰返しカウントの更新定義) {
    処理文;
}

[코드 예시 (例)]
// カウンタ変数 (카운터 변수)
for (int count = 0; count < 5; count++) {
    System.out.println(num + " ");
    num++; // numの値に1加算 (num 값에 1 가산)
}

[Point 💡]
カウントが5になった時点でFor文を終了する
(카운트가 5가 된 시점에서 for문을 종료한다)



■ for文 (for문)
⇒ 繰り返しカウントの定義と、繰り返し回数の定義、
繰り返しカウントの更新定義は省略可能
(반복 카운터의 정의, 반복 횟수의 정의, 반복 카운터의 갱신 정의는 생략 가능)

[기본 문법 구조]
for (繰返しカウントの定義; 繰返し回数の定義; 繰返しカウントの更新定義) {
    処理文;
}

[Point 💡]
繰り返しカウントの更新定義を省略するときのみ、
末尾のセミコロン省略可
(반복 카운터의 갱신 정의를 생략할 때만, 맨 끝의 세미콜론 생략 가능)

--------------------------------------------------
[例① (예시 ①)] - 카운터 정의를 외부로 뺀 경우
--------------------------------------------------
int count = 0;
for (; count < 5; count++) {
    System.out.println(num + " ");
    num++; // numの値に1加算 (num 값에 1 가산)
}

--------------------------------------------------
[例② (예시 ②)] - 카운터 갱신 정의를 내부로 뺀 경우 (세미콜론 주의!)
--------------------------------------------------
for (int count = 0; count < 5;) {
    System.out.println(num + " ");
    num++; // numの値に1加算
    count++;
}



■ 拡張for文 (확장 for 문 / 향상된 for 문)
⇒ 配列などの全要素を順番に取り出して繰り返し処理ができる文
(배열 등의 모든 요소를 순서대로 꺼내어 반복 처리를 할 수 있는 문)

[기본 문법 구조]
for (変数宣言 : 参照変数名) {
    処理文;
}

[Point 💡]
・変数宣言 (변수 선언)
⇒ 配列などから取り出した値をどのデータ型、変数名で扱うか定義
(배열 등에서 꺼낸 값을 어떤 데이터형, 변수명으로 다룰지 정의)
・参照変数名 (참조 변수명)
⇒ どの配列を参照するか指定
(어떤 배열을 참조할지 지정)

[코드 예시 (例)]
char[] array = { 'a', 'b', 'c', 'd', 'e' };
for (char c : array) {
    System.out.println(c + " ");
}

■반복제어문

⇒반복처리안에서, 어떤 특정의 조건이 발생할 경우에 특별한 제어를 하기 위한 문

break문
⇒실행중의 반복처리를 중단해서 빠져나올 때 사용.

continue문
⇒반복처리를 중단하지 않고, 반복안의 남은 처리를 스킵하고 조건식에 제어로 이동한다.


■ 繰り返し制御文1 (반복 제어문)

break文
⇒ 実行中の繰返しを中断して抜け出す時に使う
(실행 중인 반복을 중단하고 빠져나올 때 사용)

[코드 예시 (例)]
for(int i = 0; ; i++){ // 繰り返し回数を定義していないので、無限ループになる
    if(i == 3){
        `break;`
    }
    System.out.println(i + " ");
}
System.out.println("for文終了");

[Point 💡]
変数iが3になったら、if文ではなく、for文を抜ける
(변수 i가 3이 되면, if문이 아니라 for문을 빠져나간다)


■ 繰り返し制御文2 (반복 제어문)

continue文
⇒ 繰り返し処理を中断せず、
  繰り返し内の残りの処理をスキップして条件式に制御を移す
  (반복 처리를 중단하지 않고, 반복 안의 남은 처리를 스킵하여 조건식으로 제어를 옮긴다)

[코드 예시 (例)]
for(int i = 1; i < 10; i++){
    if((i % 3) == 0){
        System.out.println("処理をスキップ");
        `continue;`
    }
    System.out.println(i + " ");
}
System.out.println("for文終了");

[Point 💡]
変数iを3で割った余りが0になる
⇒ 変数iが3の倍数の時、処理をスキップする
(변수 i를 3으로 나눈 나머지가 0이 된다 ⇒ 변수 i가 3의 배수일 때, 처리를 스킵한다)

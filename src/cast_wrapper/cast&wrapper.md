# 형변환(cast)

==================================================
1. 암묵적 형변환 (자동, Promotion)
⇒ 범위가 작은것에서 범위가 큰 것으로
==================================================
   byte ➔ short ┐
                ├──> int ➔ long ➔ float ➔ double
          char──┘

==================================================
2. 캐스트에 의한 형변환 (강제, Casting)
⇒ 범위가 큰것에서 범위가 작은 것으로(수동으로 형변환 / 안하면 컴파일 에러)
==================================================
   byte <─ short ┌
                <── int <── long <── float <── double
          char <─┘



■형변환의 주의점

💡 演算時のルール (연산 시의 규칙)

① 一方のオペランドが double
⇒ もう一方も double に
(한쪽 피연산자가 double이면, 나머지 한쪽도 double로 변환)

② 一方のオペランドが float
⇒ もう一方が double でない場合、float に
(한쪽 피연산자가 float이고, 나머지 한쪽이 double이 아니면, float로 변환)

③ 一方のオペランドが long
⇒ もう一方が float、double でない場合、long に
(한쪽 피연산자가 long이고, 나머지 한쪽이 float나 double이 아니면, long으로 변환)

④ 上記に該当しない場合、演算前に双方は int 型に
(위의 어디에도 해당하지 않는 경우, 연산 전에 양쪽 피연산자 모두 int형으로 변환 - byte, short, char 등의 연산)


예①
byte b1 = 10;   // OK
byte b2 = 150;  // 컴파일에러
👉byte형은 -128 ~ 127까지 다룸..


예②
short s1 = 10;  // OK
s1 = ++s1;      // OK
s1 = s1 + 1     // ❌컴파일에러
👉단순 연산자를 이용할 경우는 형변환 불필요이지만,
  연산시의 룰에따라 한쪽의 피연산자가 int형으로 변환 되기 때문에, 컴파일에러가 된다.




# Wrapper 클래스
⇒ 기본 데이터형의 클래스를, `참조형으로서 다루기위한 클래스`

==================================================
基本データ型 (기본형)    |  ラッパークラス (래퍼 클래스)
==================================================
boolean         　　　 |  Boolean
char             　　　|  Character
byte             　　　|  Byte
short            　　　|  Short
int              　　　|  Integer  (⚠️ 이름 전체 변경)
long             　　　|  Long
float            　　　|  Float
double           　　　|  Double

`Boxing`   = 기본 데이터형에서 래퍼클래스로의 자동 변환
`Unboxing` = 래퍼클래스에서 기본 데이터형으로의 자동 변환

예
int i1 = 100;
Integer obj = i1;  // Boxing
Int i2 = obj;       // Unboxing

💡Point💡
Boxing에서는 암묵적인 형변환이 행해지지않기 때문에 주의!!
